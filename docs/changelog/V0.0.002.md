# NW-API V0.0.002

> NW-API 白标控制台体验优化：精简控制台首页、重构更新入口、强化安全更新说明。

- 控制台首页顶部精简：删除最上方“概览”和账号邮箱显示，减少重复信息
- 控制台主标题调整：由“控制台概览”改为“控制台”
- 更新入口重构：删除左侧菜单“系统更新”，将更新入口合并到左上角版本号区域
- 版本号状态提示：有新版本时版本号变色并显示 NEW，鼠标悬停提示发现新版本
- 更新操作入口：点开版本号区域后可选择“立即更新”和“查看更新内容”
- 品牌文字精简：删除界面中的“API Console”字符，左上角仅保留 NW-API 与版本号
- 安全更新约束：更新仅覆盖功能代码，不覆盖用户、数据库、Sub2API 连接、密钥配置和运行环境配置
- 验证完成：已完成登录、控制台、版本显示、更新入口与服务健康检查

---

## 📥 更新方式

**管理员在线更新：**

登录 NW-API 管理员控制台，在左上角版本号区域查看更新提示并执行更新。

**服务器手动更新：**

```bash
cd /opt/nw-api-stack
git pull --ff-only
sudo ./scripts/deploy-aliyun.sh
```

**预览环境更新：**

```bash
cd /opt/nw-api-stack
git pull --ff-only
sudo ./scripts/deploy-preview-host.sh
```
