# NW-API V0.0.3-rc.2：真实上游并发保护

时间：2026-07-07
范围：9088 预览栈 + RC2 构建；正式站未更新。

## 目标

在真实上游高并发验证后，避免 NW-API 把过量并发直接打到 Sub2API/上游，改为在 wrapper 层先保护：

- 全局上游并发默认：12
- 单 Key 上游并发默认：10
- 超限返回：HTTP 429 `NW_UPSTREAM_BUSY`
- 超限只写 access log，不写 usage/wallet，不产生 shadow 扣费

## 代码变更

`services/xapi-v1-wrapper/xapi_v1_wrapper.py`

新增环境变量：

- `XAPI_UPSTREAM_MAX_CONCURRENCY`，默认 12
- `XAPI_UPSTREAM_MAX_CONCURRENCY_PER_KEY`，默认 10

新增逻辑：

- `_UPSTREAM_GLOBAL_SEMAPHORE`
- `_UPSTREAM_KEY_COUNTS`
- `acquire_upstream_slot()`
- `release_upstream_slot()`

请求在转发真实上游前先抢占 slot；失败则立刻返回 `NW_UPSTREAM_BUSY`。
