凭证

账号与 Key

用户应妥善保管账号、密码和 API Key。发现泄露、异常调用或账号被盗用时，应立即禁用 Key 并联系管理员。

用途

禁止行为

不得用于违法违规、攻击、滥发、绕过安全限制、侵犯第三方权益、批量探测或明显超出约定用途的行为。

额度

余额与限制

请求可能受到余额、套餐、模型权限、并发、上游状态和风控策略共同限制。

稳定

可用性说明

模型供应商、网络链路、维护、风控和异常流量可能影响可用性；平台会尽力保持稳定并提供必要提示。

审计

日志与复核

平台可记录必要日志用于账务、排障、安全审计和争议复核。异常场景可能触发限速、暂停 Key 或人工复核。

变更

规则调整

价格、模型、额度、风控和服务规则可能根据运营需要调整；以官网、控制台或管理员通知为准。

使用建议：生产环境接入前先用小流量验证模型、额度、错误处理和降级策略；不要把 API Key 放在客户端或公开环境。
