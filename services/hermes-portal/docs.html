接入文档 · 标准 /v1 接口

把现有应用接入 NW-API。

使用兼容主流 SDK 的调用方式，统一管理 Key、模型权限、用量记录和风控策略。公开文档只展示必要接入信息，具体额度和可用模型以控制台为准。

进入控制台创建 Key查看可用模型
curl https://of.ahner.cn/v1/models \
  -H "Authorization: Bearer YOUR_API_KEY"

# Chat Completions
curl https://of.ahner.cn/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"请在控制台选择","messages":[{"role":"user","content":"hello"}]}'
1

创建 Key

登录控制台创建 API Key。完整 Key 只在创建或查看时展示，请勿放入公开仓库、截图或前端代码。

2

替换 Base URL

把 SDK 的 Base URL 设置为 https://of.ahner.cn/v1，其余调用方式保持兼容。

3

查看用量

在控制台查看请求、Token、余额、Key 状态和异常提示；生产接入前先做小流量验证。

Python

SDK 示例

from openai import OpenAI client = OpenAI( base_url="https://of.ahner.cn/v1", api_key="YOUR_API_KEY", ) res = client.chat.completions.create( model="请在控制台选择", messages=[{"role":"user","content":"hello"}], ) print(res.choices[0].message.content)
Node.js

SDK 示例

import OpenAI from "openai"; const client = new OpenAI({ baseURL: "https://of.ahner.cn/v1", apiKey: process.env.NW_API_KEY, }); const res = await client.chat.completions.create({ model: "请在控制台选择", messages: [{ role: "user", content: "hello" }], });

鉴权

每个请求使用 Authorization: Bearer YOUR_API_KEY。Key 被禁用、余额不足或模型未授权时会返回明确错误。

模型权限

可用模型、价格和额度以控制台与模型页面为准。不同账号可能拥有不同模型范围。

安全建议

服务端保存 Key，避免写入客户端包、浏览器 localStorage、公开日志或工单截图。

常见排查顺序：确认 Key 状态 → 检查余额和额度 → 检查模型权限 → 查看控制台用量与通知 → 再联系管理员复核。

准备开始接入？

先创建 Key，再用小流量验证模型、额度和返回格式。
