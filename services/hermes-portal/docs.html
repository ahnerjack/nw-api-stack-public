接入概览

NW-API 提供统一的 /v1 API 入口，用于管理 API Key、模型权限、用量统计、余额和风控策略。生产接入前建议先创建测试 Key，小流量验证返回格式和错误处理。

1. 创建 Key登录控制台创建并保存访问凭证。
2. 替换地址把 SDK Base URL 设置为平台 /v1 地址。
3. 查看用量在控制台查看调用、余额、Token 和异常。

快速开始

Base URL：

https://of.ahner.cn/v1

查看模型

curl https://of.ahner.cn/v1/models \ -H "Authorization: Bearer YOUR_API_KEY"

发送对话请求

curl https://of.ahner.cn/v1/chat/completions \ -H "Authorization: Bearer YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{"model":"请在控制台选择","messages":[{"role":"user","content":"hello"}]}'

鉴权

所有 API 请求都需要携带：

Authorization: Bearer YOUR_API_KEY

Key 被禁用、余额不足、模型未授权、额度不足或触发风控时，请求会返回明确错误。请不要把完整 Key 放在浏览器前端、公开仓库、截图、日志或工单中。

SDK 示例

Python

from openai import OpenAI client = OpenAI( base_url="https://of.ahner.cn/v1", api_key="YOUR_API_KEY", ) res = client.chat.completions.create( model="请在控制台选择", messages=[{"role":"user","content":"hello"}], ) print(res.choices[0].message.content)

Node.js

import OpenAI from "openai"; const client = new OpenAI({ baseURL: "https://of.ahner.cn/v1", apiKey: process.env.NW_API_KEY, }); const res = await client.chat.completions.create({ model: "请在控制台选择", messages: [{ role: "user", content: "hello" }], });

模型与权限

项目说明
可用模型以控制台和模型页面为准，不同账号可能拥有不同模型范围。
价格以价格页面和控制台展示为准，按用量记录和账户余额核算。
额度余额、套餐、Key 状态、模型权限、并发和风控策略会共同影响调用。

错误与排查

建议按以下顺序排查：

确认 Key 状态 → 检查余额和额度 → 检查模型权限 → 查看控制台用量与通知 → 复核请求路径和参数 → 联系管理员。

常见原因

Key 无效、余额不足、模型未授权、超过并发/额度限制、请求过快、异常路径、违反服务条款或上游临时不可用。

安全建议

服务端保存 Key，客户端只调用自己的后端。定期轮换 Key，发现泄露立即禁用。生产环境应记录请求 ID、错误码和必要上下文，但不要记录完整 Key 或敏感业务内容。
